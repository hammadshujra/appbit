# Appbit V2.7

Cloudflare R2 account/file manager derived from the supplied HS Local File Manager R2 reference, rebuilt natively for the Appbit Node/MySQL architecture.

Core capabilities:
- Multiple R2 accounts and buckets.
- AES-256-GCM encrypted secrets.
- Connection test and object sync.
- Resumable multipart upload with 5 MiB baseline retryable parts, adaptive browser concurrency, and a long slow-connection request window.
- Upload, replace, delete, search, and copy/open links.
- Default opaque object keys.
- Direct custom-domain links or an opaque Appbit gateway `/d/<token>` with HTTP Range forwarding.
- R2 objects and upload sessions stored in MySQL schema 129.

Cloudflare service limits still apply. Multi-account usage remains subject to Cloudflare's terms and billing for each account.
