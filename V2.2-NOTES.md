# Appbit V2.2.0

This release targets incomplete LiteAPKs metadata and update/import jobs that appear to stop when the browser page is no longer driving them.

Key fixes:
- Secondary-source metadata enrichment now initializes page text before size/date fallback parsing.
- Strongly typed compact-stat parsing handles LiteAPKs layouts where values such as `17 MB` appear above the `SIZE` label.
- REACHED/views is retained as the source popularity/download counter when no separate downloads value exists.
- Update scans continue in a background server worker once started.

Docker upgrade: keep `.env.docker` and existing database volumes. Replace application files and rebuild with `docker compose up -d --build`.
