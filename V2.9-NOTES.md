# Appbit V2.9 — Hostinger Next.js Build

- Replaced the Astro UI middleware with Next.js 16.3.3.
- Preserved the existing Express backend, authentication, MySQL schema, LiteAPKs resolver, publishing/update workers, R2 Accounts and R2 File Manager.
- Added a custom Next.js server so `/api/*`, `/login`, `/health`, `/d/:token` and authenticated UI routes continue to use the same backend behavior.
- Next.js assets are served before Appbit authentication; application pages remain authentication-protected.
- Added Hostinger-ready build settings, `hostinger.env.example`, and Hostinger deployment documentation.
- Hostinger target: Node 24, build output `.next`, entry `server.js`.
- Database schema remains 130.
