# Appbit V2.6

- Reorganized the app detail workspace around a 20/80 metadata/content layout.
- Removed the duplicated app icon from the Artwork section; the identity icon remains only in the app header.
- Download Media now packages the icon, cover, every available screenshot, and a media manifest in one ZIP.
- Meta title, meta description, description, and Mod Info now use separate content cards.
- Added LiteAPKs compact size parsing for values such as `147 M` and `1.6 G` (interpreted as MB and GB).
- Preserved the existing publishing, R2, team, and database behavior.
