# Appbit V2.8

V2.8 reorganizes Cloudflare R2 into two dedicated admin pages:

- **R2 Account → Accounts**: connect multiple R2 accounts/buckets, test and sync them, see indexed usage and tracked remaining capacity, and configure the public download subdomain.
- **R2 Account → File Manager**: upload, resume, search, replace, delete, and copy/open links for files across all connected accounts.

The account form intentionally exposes only the required values: Account Label, Enabled/Disabled, Cloudflare Account ID, Bucket Name, Access Key ID, and Secret Access Key. Appbit derives the S3 endpoint automatically and uses region `auto`.

The 10 GB value shown per account is a **tracking/planning target**, calculated from Appbit's indexed bucket contents. It is not a Cloudflare billing-quota API reading. Use **Sync Files** after changes made outside Appbit.

Download-domain setup generates both:
1. a TXT ownership-verification record, and
2. a CNAME routing target to the current public Appbit hostname when one is available.

The TXT record verifies ownership; the CNAME is what routes download traffic. After TXT verification, Appbit uses that hostname in `/d/<opaque-token>` public links.
