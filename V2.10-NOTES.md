# Appbit V2.10 — Hostinger Webpack Build Fix

V2.10 is a deployment compatibility release for Hostinger.

- Next.js remains pinned to 16.3.3.
- Production builds explicitly use Webpack: `next build --webpack`.
- This avoids the Hostinger Linux/x64 Turbopack native-binding failure when only the WASM compiler binding is available.
- The runtime remains the existing custom Next.js + Express server (`server.js`).
- Database schema remains 130. No database reset or migration is required for this build-system change.
- All Appbit V2.8/V2.9 application features remain unchanged.

Visible version: **V2.10**.
